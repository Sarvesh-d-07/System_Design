# System Design E-Commerce

A simple e-commerce application built with a system-design-first approach.

## Project Structure

```text
System_Design/
├── client/       # Customer-facing e-commerce application
├── dashboard/    # Admin dashboard
└── docs/         # System design documentation
```

The client contains the storefront, product pages, shop, cart, reusable components, and product/cart features. 

The dashboard is used for administrative functionality. The project also includes documentation covering requirements, HLD, LLD, database design, APIs, SOLID principles, design patterns, scalability, security, observability, ADRs, and AI-assisted validation.  

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS
* Vite
* Recharts

## Getting Started

### Client

```bash
cd client
npm install
npm run dev
```

### Dashboard

```bash
cd dashboard
npm install
npm run dev
```

## Goal

The goal of this project is to build an e-commerce system while applying practical system design principles, clean architecture, scalability, reliability, security, and maintainability.
